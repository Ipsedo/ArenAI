# Event-only reward refactor (aim shaping removed = camping cause), timeout ratio removed, run 398_silu

Runs: 353 (cited), 386, 388-397, 398_beta, 398_silu, 399, 400

2026-09 — aim shaping removed from the reward (cause of camping), 100 % event-based reward; 2026-09-13: timeout ratio removed from the proprio; 2026-09-16: run 398_silu — silu > tanh, but ev≈0 since the removal (critic blind to starvation).

2026-09-09: the ppo_liquid run had converged to camping (aims/hits from spawn, no longer moves). Cause: the `aim` term (0.1 × aim_quality) was computed against the enemy's true position without line of sight — paid without perceiving. Refactor validated: `aim` removed from the reward (get_reward = hit + received + death, + win), TrackedShell machinery kept for `miss`/`r_aim` metrics (inert). Starvation as the only urgency. New run **from scratch** (no weight reuse — Samuel does not care about the trained model).

**Why:** movement must be instrumental (search in order to hit), not rewarded; event terms physically require line of sight, zero camping loophole.

2026-09-13: the timeout ratio (remaining_frames/30 s, added 2026-09-04 with starving in JoltEnemyTank) is **removed from the proprioception** (134 features). Never ablated, no proof of gain (386, last run without, remained the best of the period); in game `apply_timeout=false` but the counter still decremented → obs pinned to 0 in long games = rare-terminal state never inhabited in training → spraying (permanent despair). The starvation mechanism stays (training only). Networks saved with the ratio (388-397, incl. liquid) are incompatible — from scratch anyway.

2026-09-16 — analysis train_398_ppo_liquid_beta_silu (vs 398_beta tanh and 397, at equal duration ~6900 rows): **silu > tanh** everywhere (hitR 0.066 vs 0.058, kills 6.4 vs 4.7, curriculum D 1000 vs 850 reached). The « stagnation » of hitR/kill is mostly an artefact: 94 % of the run under growing curriculum (D 250→1000, real mean distance 250→640 m); at fixed D=1000 it still progresses (hitR 0.058→0.066). **Real problem: ev≈0 all run** (397 with timeout ratio in proprio: ev 0.42-0.49; both 398 without: ev≈0). The starvation timer decides deaths (terminal done in GAE) but is no longer observable → unpredictable returns → noisy advantages. kl≈0.0025 (target 0.05), clip ~3 %, Hc held by PID: no sign of saturation of the 128 neurons — the bottleneck is the critic, not capacity.

**Implemented 2026-09-16 (validated by Samuel)**: starvation = truncation + penalty −2 kept. Core tuple widened to `(State, Reward, IsDone, IsTruncated)`; death cause latched in `JoltEnemyTank` (`starved`, since the timer continued after a combat death); GAE of both PPO: `deltas = r + γ·(next_values·(1−dones) + values·truncateds) − values` (bootstrap on **V(s_t)**, the last living obs — the post-mortem wreck is not a state of the counterfactual MDP and V is never trained there); GAE recurrence always cut by `dones`; SAC: target with soft_value(state) for truncated steps. Winner/suicide stay terminal; the global episode timeout was already a correct truncation via bootstrap_state.

Run 399 (truncation + penalty −2): ev does NOT rise (397 was already at 0.5-0.6 at the same age, ~150 rows). Diagnosis: the invisible −2 starvation remains an unpredictable shock of the same order as the cut (γ=0.997 → contribution −0.8 to −1.2 at 5-10 s from starvation, vs V≈0.2); early in the run most deaths are starvations. **2026-09-16: starvation penalty removed** (pure truncation, `detail.death = is_dead() && !is_timeout() ? -1 : 0`) — combat/suicide deaths keep −1. In reserve if ev still does not rise: starvation timer visible to the critic only.

Run 400 (pure trunc), first ~200 rows: **best of the 4 runs at same age** — stable positive ev 0.2-0.3 without dip (first time since the timer removal), hitR 0.062, kills 4.9, aim 0.38, no camping (fire ~1/s stable). Mean r −0.0002 vs −0.0017 before: the −2 starvation was ~85 % of the reward mass, so ev of 397 (0.5) is not comparable (it mostly predicted starvations via the timer). Watch: slight ev settling (0.32→0.19, critic chasing a fast-progressing policy?) and ev holding at curriculum opening (D>250).
